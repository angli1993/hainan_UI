# 前端样板架构

## 目标

本仓库用于先行验证医生端信息架构和交互，再将批准后的设计迁移到正式平台。它不是正式前端的分叉，也不应复制后端业务规则。

## 页面关系

```text
Agent 工作台 / 量表导入
        |
        +-- 患者随访 / 字段字典 / 导入历史
        |
        +-- 神经影像
        |     +-- 静息态 fMRI
        |     +-- DWI / DTI
        |     +-- T1 加权结构像
        |     +-- 资源与设置 / 平台图谱库
        |
        +-- 神经电生理
              +-- 静息态 EEG（规划）
```

每种模态保留相同的医生端阅读结构：队列概况、该模态的真实处理流程、特征选择、本次方案。阶段数量和名称由处理语义决定，不强制套用统一四阶段。阶段详情只解释所点阶段，结果卡只解释对应结果。

```text
fMRI: BIDS 数据 -> fMRI 预处理 -> BOLD 信号去噪 -> fMRI 特征提取
DWI:  BIDS 数据 -> DWI 预处理 -> 扩散模型拟合 -> DTI 特征提取
T1:   BIDS 数据 -> FreeSurfer 结构像处理 -> 脑区形态特征提取
                -> deepmriprep VBM 处理 -> VBM 特征提取
EEG:  EEG-BIDS 数据 -> EEG 预处理 -> EEG 特征提取（规划）
```

BIDS 转换发生在 Agent 工作台。模态页面的 BIDS 节点只读显示可用检查、验证结果和失败原因，不提供转换参数。结果登记是平台自动行为，不显示为神经影像处理阶段。

fMRI 的“BOLD 信号去噪”包括混杂信号回归、高头动帧处理和按指标配置的时域滤波，不代表一份供所有指标共用的全局结果。选择特征后，前端加载该特征的推荐去噪方案；正式后端根据输入、软件与参数版本、输出空间、图谱及特征参数形成不可变工件身份，并查找最深的兼容缓存节点。前端只展示匹配结果，不使用 Agent/LLM 决定处理流程。参数变化只使其后的不兼容节点重新计算。

平台图谱库是神经影像公共资源页，不属于任一模态管线。特征详情中的图谱入口复用同一目录，并按特征、结果空间、启用状态和已登记变换过滤。脑区形态使用 FreeSurfer 原生分区，不进入平台体积图谱选择。

## 状态边界

- 样板状态保存在浏览器 `localStorage`，只用于演示选择和参数。
- 阶段人数为合成数据，不调用 API。
- 正式接入时，阶段人数应由任务状态聚合接口返回；前端不自行推断状态。
- 正式接入时，患者数按唯一患者去重，检查次数按患者与随访会话计数。

## 后续拆分原则

当样板进入正式实现阶段，再按页面、状态 hook、API 客户端和展示组件拆分。未确定正式框架前，不为样板引入框架或重复建设组件库。
