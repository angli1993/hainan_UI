# 前端样板架构

## 目标

本仓库用于先行验证医生端信息架构和交互，再将批准后的设计迁移到正式平台。它不是正式前端的分叉，也不应复制后端业务规则。

## 页面关系

```text
Agent 工作台 / 量表导入
        |
        +-- 患者随访 / 字段字典 / 导入历史
        |
        +-- 神经影像
        |     +-- 静息态 fMRI
        |     +-- DWI / DTI
        |     +-- T1 加权结构像
        |     +-- 资源与设置 / 平台图谱库
        |
        +-- 神经电生理
              +-- 静息态 EEG（规划）
```

每种模态保留相同的医生端阅读结构：队列概况、该模态的真实处理流程、特征选择、本次方案。阶段数量和名称由处理语义决定，不强制套用统一四阶段。阶段详情只解释所点阶段，结果卡只解释对应结果。

```text
fMRI: BIDS 数据 -> fMRI 预处理 -> BOLD 信号去噪 -> fMRI 特征提取
DWI:  BIDS 数据 -> DWI 预处理 -> 扩散张量拟合 -> DTI 指标生成
T1:   BIDS 数据 -> FreeSurfer 结构像处理 -> 脑区形态结果生成
                -> deepmriprep VBM 处理 -> VBM 结果发布
EEG:  EEG-BIDS 数据 -> EEG 预处理 -> EEG 特征提取（规划）
```

BIDS 转换发生在 Agent 工作台。模态页面的 BIDS 节点只读显示可用检查、验证结果和失败原因，不提供转换参数。结果登记是平台自动行为，不显示为神经影像处理阶段。

fMRI 的“BOLD 信号去噪”包括混杂信号回归、高头动帧处理和按指标配置的时域滤波，不代表一份供所有指标共用的全局结果。选择特征后，前端加载该特征的推荐去噪方案；正式后端根据输入、软件与参数版本、输出空间、图谱及特征参数形成不可变工件身份，并查找最深的兼容缓存节点。前端只展示匹配结果，不使用 Agent/LLM 决定处理流程。参数变化只使其后的不兼容节点重新计算。多指标方案必须对检查级兼容集合求交集，再分别按唯一患者和检查次数聚合；不能用单指标数量的最小值代替交集。

DTI 使用 `DWI BIDS -> QSIPrep -> 扩散张量 -> FA/MD/AD/RD` 的逐层工件身份。QSIPrep 参数变化使预处理及下游失效；最大 b 值变化只使张量与指标失效；图谱变化只重新生成可选脑区汇总。体素图始终是默认结果，当前平台没有为 DTI 强制设置灰质图谱。

T1w BIDS 之后分为两条独立分支。FreeSurfer 分支生成脑区形态，使用 `aparc`、`aparc.a2009s` 和 `aseg` 原生分区；deepmriprep 分支按每次随访独立生成并发布 VBM 组织图和 GMV、WMV、CSFV、TIV。FreeSurfer 随访处理方式只影响 FreeSurfer 分支，CPU/GPU 只影响资源调度，不进入科研工件身份。VBM 默认不启用图谱汇总，也不等同于严格纵向 VBM。

平台图谱库是神经影像公共资源页，不属于任一模态管线。特征详情中的图谱入口复用同一目录，并按特征、结果空间、启用状态和已登记变换过滤。fMRI 四类指标默认使用与输出空间匹配的脑网络组图谱：`MNI152NLin2009cAsym` 对应 `BN_MNI152NLin2009cAsym_2mm`，`MNI152NLin6Asym` 对应 `BN_MNI152NLin6Asym_2mm`；用户仍可更换为其他兼容平台图谱。ALFF/fALFF 和 ReHo 在默认脑区汇总之外继续保留体素结果。脑区形态使用 FreeSurfer 原生分区，不进入平台体积图谱选择。

## 状态边界

- 样板状态保存在宿主提供的浏览器 widget state 中，只用于演示选择和参数。
- 样板队列统一显示为“海南痴呆队列”；阶段人数和检查集合为合成数据，不调用 API。
- 正式接入时，阶段人数应由任务状态聚合接口返回；前端不自行推断状态。
- 正式接入时，患者数按唯一患者去重，检查次数按患者与随访会话计数。

## 后续拆分原则

当样板进入正式实现阶段，再按页面、状态 hook、API 客户端和展示组件拆分。未确定正式框架前，不为样板引入框架或重复建设组件库。
