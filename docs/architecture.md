# 前端样板架构

## 目标

本仓库用于先行验证医生端信息架构和交互，再将批准后的设计迁移到正式平台。它不是正式前端的分叉，也不应复制后端业务规则。

## 页面关系

```text
Agent 工作台 / 量表导入
        |
        +-- 患者随访 / 字段字典 / 导入历史
        |
        +-- 神经影像
        |     +-- 静息态 fMRI
        |     +-- DWI / DTI
        |     +-- T1 加权结构像
        |
        +-- 神经电生理
              +-- 静息态 EEG（规划）
```

每种模态遵循同一医生端结构：队列概况、四阶段处理流程、结果选择、本次方案。阶段详情只解释所点阶段，结果卡只解释对应结果。

## 状态边界

- 样板状态保存在浏览器 `localStorage`，只用于演示选择和参数。
- 阶段人数为合成数据，不调用 API。
- 正式接入时，阶段人数应由任务状态聚合接口返回；前端不自行推断状态。
- 正式接入时，患者数按唯一患者去重，检查次数按患者与随访会话计数。

## 后续拆分原则

当样板进入正式实现阶段，再按页面、状态 hook、API 客户端和展示组件拆分。未确定正式框架前，不为样板引入框架或重复建设组件库。
