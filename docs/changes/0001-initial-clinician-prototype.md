# 0001 初始医生端样板仓库

状态：Verified

## 背景

现有临床平台需要在保留 Agent、量表和患者数据功能的基础上，降低神经影像与 EEG 页面对医生的认知负担。

## 目标

- 建立可独立讨论和协作的前端样板仓库。
- 保留成熟工作台结构。
- 以四阶段流程组织神经影像和 EEG 信息。
- 技术细节按阶段展开，每个入口只显示自己的内容。
- 同时展示患者数和检查次数。

## 非目标

- 不接入正式后端或数据库。
- 不实现 EEG 处理。
- 不开发群体统计模型。
- 不恢复 RBM。

## 设计

源码以 HTML 片段维护，通过零依赖脚本生成独立 `index.html`。所有数据为合成演示数据。模态页面使用“数据接入、处理、结果提取、结果登记”四阶段结构；fMRI 单独区分预处理与后处理。

## 兼容影响

独立样板仓库，不修改 `maintain_hainan` 的正式前端、后端、API 或数据库。

## 验收标准

- 原有 Agent 与量表入口可见。
- 神经影像和 EEG 导航可用。
- 阶段按钮只打开本阶段详情。
- 阶段按钮显示患者数和检查次数。
- 320 px 及以上无横向溢出。
- 控制台无错误或警告。

## 测试结果

- 静态构建和契约检查通过。
- 桌面与 390 px 响应式检查通过。
- T1 与 fMRI 阶段交互检查通过。

## 风险与回滚

阶段数量为演示数据，不能用于临床或项目管理判断。回滚时恢复上一提交即可，不影响正式平台。
