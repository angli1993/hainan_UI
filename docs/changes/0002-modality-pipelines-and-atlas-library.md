# 0002 模态专属管线与平台图谱库

状态：Verified

## 背景

初版将各模态统一组织为四个阶段，导致 BIDS 转换、特征提取和自动结果登记的边界不准确；完整图谱目录与具体特征的图谱选择也缺少清晰分工。

## 目标

- 按 fMRI、DWI、T1 和 EEG 的真实处理语义展示不同管线。
- 将 BIDS 转换明确归属 Agent 工作台，模态页只读展示 BIDS 数据状态。
- 将完整图谱库作为神经影像公共资源页面。
- 具体特征仅从同一图谱库中选择当前任务兼容的图谱。
- T1 明确显示 FreeSurfer 脑区形态与 deepmriprep VBM 两条分支。

## 非目标

- 不修改正式前端、后端、API、数据库或任务调度。
- 不实现图谱导入、启停或真实影像预览。
- 不恢复 RBM，不新增群体统计模型。
- 不宣称 EEG 后端已经接入。

## 设计

模态页继续使用队列概况、可点击流程、特征选择和本次方案，但流程节点不再固定为四个。BIDS 节点关闭编辑操作；T1 使用一个共享 BIDS 输入和两条并列处理分支。结果登记从可见流程中移除，作为平台自动溯源行为保留在产品契约中。

左侧“神经影像”导航增加“资源与设置 / 平台图谱库”。该页展示现有 57 个目录图谱的名称、家族、空间、标签数和审核状态。特征卡的图谱弹窗继续读取同一目录，但只列出已启用且满足当前空间和变换约束的图谱。

## 兼容影响

独立样板的数据仍保存在浏览器状态中。原有 Agent、量表、患者随访、字段字典和导入历史入口不变；没有新增后端契约。

## 验收标准

- fMRI、DWI、T1 和 EEG 显示各自管线名称与阶段数量。
- BIDS 节点只读，并说明转换发生在 Agent 工作台。
- T1 同时显示 FreeSurfer 和 deepmriprep VBM 分支。
- 平台图谱库可从神经影像导航进入并检索、按空间筛选。
- 特征图谱弹窗只显示当前任务兼容图谱。
- 脑区形态明确使用 FreeSurfer 原生分区。
- 桌面、390 px 和 320 px 布局无横向溢出，控制台无新增错误。

## 测试结果

- `npm test` 通过。
- 桌面、390 px 和 320 px 浏览器检查通过。
- BIDS、T1 分支、图谱库检索和特征图谱选择交互通过。

## 风险和回滚

阶段人数、检查次数和图谱审核状态仍为演示数据，不能用于临床或项目管理判断。回滚时撤销本变更即可，不影响正式平台。
