# 0004 复刻平台图谱查看工作台

状态：Verified

## 背景

样板的“平台图谱库”只有 57 条资源的长表格，缺少正式平台 `AtlasPanels.tsx` 与 `BrainViewer.tsx` 已有的目录—详情结构、脑图查看和标签定位能力，不能准确展示现有平台能力。

## 目标

- 复刻原平台左侧图谱目录、右侧详情工作区的主要信息架构。
- 保留图谱名称/编号搜索、模板空间筛选、交接状态、标签数和启停状态。
- 展示三平面加 3D、单视图切换、十字线、透明度和当前脑区反馈。
- 恢复标签表搜索、颜色、半球、模板体素、定位和每页 50 条的分页结构。
- 在图谱详情中预留逐图谱的推荐引用、DOI 和资源来源区。

## 非目标

- 不修改正式前端、后端、API、数据库或任务调度。
- 不在零依赖样板中复制 NiiVue 或嵌入真实 NIfTI 文件。
- 不恢复已从图谱页移除的“被试空间图谱”面板；目标空间变换仍属于具体特征计算。
- 不把导入状态解释为解剖、配准或许可已经通过科研验收。

## 设计

图谱页使用与正式平台一致的目录—详情布局。目录读取样板中现有的 57 条平台图谱记录；选择图谱后显示完整名称、家族、模板空间、网格、体素尺寸、标签数及交接状态。

右侧查看器保留原平台 NiiVue 的交互轮廓，但使用本地 Canvas 绘制明确标记为“交互示意”的脑图，避免把样板图当作真实影像。正式接入时继续使用原平台锁定的 `@niivue/niivue`、真实模板背景、图谱 NIfTI 和原始标签表。

参考文献默认收起。有可靠记录的常用图谱展示推荐引用和 DOI，其余显示“待补录”；正式接入后应由资源管理员维护的图谱元数据返回，不根据文件名自动推断。样板没有真实详情接口，因此图像尺寸显示为“待接口返回”，分辨率只标明来自文件名，避免把推导值当作科研元数据。

## 兼容影响

仅影响独立医生端样板。特征配置中的图谱选择弹窗和 57 条目录记录不变，没有新增后端契约或依赖。

## 验收标准

- 图谱页使用目录—详情双栏布局，窄屏自动改为单栏。
- 搜索与空间筛选会同步更新目录和详情选择。
- 四视图、轴位、冠状位、矢状位和 3D 按钮均能更新画布。
- 透明度、脑图指示、标签搜索、定位和分页可操作。
- 参考文献可展开；无记录时显示明确的待补录状态。
- 页面明确区分样板示意和正式 NiiVue/真实图谱数据。
- 桌面、390 px 和 320 px 无页面级横向溢出或文字遮挡。

## 测试结果

- `npm test`：通过（构建生成 `index.html`，静态检查通过）。
- `git diff --check`：通过。
- 浏览器交互：57 条目录正常；`Yeo` 搜索返回 4 条；模板空间筛选、五种视图、透明度、标签搜索、定位和 50 条分页均通过。
- 参考文献：Schaefer 推荐引用和 DOI 可展开；无记录图谱显示待补录状态。
- 响应式：桌面、390 px、320 px 无页面级横向溢出；标签表在窄屏使用容器内横向滚动。
- 浏览器控制台：无错误或警告。

## 风险和回滚

样板画布和标签内容不是实际 NIfTI/标签表，不能用于科研解释；页面已在查看器和说明区同时标注。回滚时撤销本变更即可，正式平台与图谱数据不受影响。
