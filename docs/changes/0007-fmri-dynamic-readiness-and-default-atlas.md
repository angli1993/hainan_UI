# 0007 fMRI 动态准备度与默认图谱

状态：Verified

## 背景

fMRI 页面顶部管线仍使用固定的 ReHo 演示人数，选择 ALFF/fALFF、功能连接或功能梯度后会与右侧方案不一致。多指标方案以最小复用数代替检查级集合计算，不能表达不同指标兼容检查的真实交集。页面也没有在默认视图中明确展示所用图谱。

## 目标

- 队列名称统一为“海南痴呆队列”。
- ALFF/fALFF、ReHo、功能连接和功能梯度默认使用平台现有的 `BN_MNI152NLin2009cAsym_2mm`，页面显示为“脑网络组图谱（BN 210）”。
- 顶部 BOLD 信号去噪和特征提取数量随当前所选指标动态变化。
- 多指标准备度按检查集合求交集，并按患者去重显示涉及人数。
- 统一区分“已具备”“已完成”“本方案需补充”和“本次待计算”。
- 在指标卡和本次方案中直接显示当前图谱；技术详情保留平台文件名、空间和更换入口。

## 非目标

- 不修改正式项目、后端、数据库或任务调度。
- 不实现真实队列筛选、缓存查询或患者级状态接口。
- 不改变平台图谱目录，不新增或重命名图谱文件。
- 不改变 DWI、T1 或 EEG 的处理契约。

## 设计

样板使用 146 次可分析检查和 104 位患者的合成身份集合。每个指标维护确定性的兼容检查集合；单指标复用数保持原演示值，多指标“无需补充处理”数量取所选指标兼容集合的交集。需要补充 BOLD 去噪的检查取该交集相对于 146 次检查的补集，患者数按检查对应的患者身份去重。

顶部阶段使用不同且明确的状态口径：

```text
BIDS 数据：已具备
fMRI 预处理：已完成
BOLD 信号去噪：本方案需补充
fMRI 特征提取：本次待计算
```

当前 fMRI 输出空间为 `MNI152NLin2009cAsym` 时，四个指标默认选择 `BN_MNI152NLin2009cAsym_2mm`。切换到 `MNI152NLin6Asym` 后，默认项随空间切换为平台已有的 `BN_MNI152NLin6Asym_2mm`。体素型指标继续保留体素图输出。

## 兼容影响

- 旧样板状态首次加载时迁移到新的 fMRI 默认图谱；迁移后仍可从平台图谱库更换为其他兼容图谱。
- 指标卡增加简短图谱摘要，可能增加单行高度，但不改变选择和展开方式。
- 所有计数继续标注为合成演示数据，不代表真实任务状态。

## 验收标准

- 页面显示“海南痴呆队列”。
- 四个 fMRI 指标默认显示“脑网络组图谱（BN 210）”。
- 默认 ReHo 显示 48 次检查需要补充去噪，切换功能连接后同步变为 34 次。
- 同时选择 ReHo 与功能连接时，顶部与右侧使用检查级交集结果且数字一致。
- fMRI 阶段分别使用“已具备”“已完成”“本方案需补充”“本次待计算”。
- 右侧本次方案显示当前图谱和 MNI 空间。
- 桌面、390 px 和 320 px 无横向溢出、文字遮挡或控制失效。
- `npm test` 与 `git diff --check` 通过。

## 测试结果

- `npm test`：通过；已重新生成 `index.html`，静态契约检查通过。
- `git diff --check`：通过。
- 浏览器交互：ReHo 为 38 位患者 / 48 次检查需补充去噪；功能连接为 26 位患者 / 34 次检查；ReHo + 功能连接为 51 位患者 / 67 次检查。
- 功能连接 + 功能梯度在方案、图谱和去噪参数一致时，共享兼容中间产物并显示 26 位患者 / 34 次检查需补充去噪。
- 标准空间从 `MNI152NLin2009cAsym` 切换到 `MNI152NLin6Asym` 后，默认图谱同步切换为 `BN_MNI152NLin6Asym_2mm`。
- 桌面、390 px 和 320 px 浏览器检查无页面横向溢出；控制台无 warning / error。

## 风险和回滚

- 合成检查集合仅用于验证聚合逻辑和界面，不可迁移为正式科研数据。
- 正式系统必须由后端按检查和患者身份聚合，不能依赖前端生成集合。
- 可回滚到提交 `e09575a`，恢复固定演示阶段人数和原默认图谱范围。
