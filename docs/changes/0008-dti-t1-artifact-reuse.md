# 0008 DTI 与 T1 分支缓存复用

状态：Verified

## 背景

DTI 和 T1 页面已有专业阶段与 T1 分支结构，但阶段人数仍为固定占位值，右侧方案没有区分最终结果复用、中间产物复用和需要从上游补算的检查。fMRI 已验证检查级集合聚合与最深兼容节点展示，需要将同一原则按各模态真实处理语义扩展到 DTI 和 T1。

## 目标

- DTI 按 `DWI BIDS -> QSIPrep -> 张量拟合 -> FA/MD/AD/RD -> 可选脑区汇总` 展示缓存复用。
- T1 在共同 BIDS 节点后保留 FreeSurfer 脑区形态和 deepmriprep VBM 两条独立分支。
- 顶部阶段、右侧方案、阶段详情和分析前检查使用同一套检查级集合与患者去重结果。
- 明确区分最终结果可直接使用、中间产物可复用、需要补充处理和暂不可分析。
- 参数变化只使变化节点及其下游失效，不无条件重跑 BIDS 或其他独立分支。

## 非目标

- 不修改正式平台、后端、数据库或任务调度。
- 不引入 DKI、NODDI、纤维追踪或束级统计。
- 不为 DTI 强行指定灰质图谱；首版默认保留 FA、MD、AD、RD 体素图。
- 不启用 VBM/RBM 默认图谱汇总，不改变此前暂缓的 VBM 图谱统计范围。
- 不实现严格纵向 VBM；deepmriprep 仍按每次随访独立处理。

## 设计

DTI 使用嵌套的合成检查集合表示已有 QSIPrep、已有兼容张量和已有最终体素指标。修改 QSIPrep 参数会使预处理及下游缓存失效；修改最大 b 值只使张量及下游缓存失效；修改图谱只新增脑区汇总任务，不重算体素图。

T1 使用同一批合格 T1w 检查分别建立 FreeSurfer 与 VBM 缓存集合。选择或调整一个分支不影响另一个分支。FreeSurfer 的逐随访与纵向模板属于产物身份；运行设备只影响资源，不改变科研产物身份。VBM 已完成时直接发布组织图和总体积，未来的图谱汇总只读取未平滑调制组织图。

医生端阶段状态使用：

```text
BIDS 数据：已具备
处理阶段：本方案需补充
结果阶段：可直接使用 / 本次待生成
```

正式后端应返回每次检查的工件状态和不兼容原因；前端只聚合和展示确定性结果。

## 兼容影响

- DTI 和 T1 原有参数入口、结果选择和图谱入口保留。
- DTI 默认仍为体素输出，已有用户主动选择的兼容图谱继续保留。
- T1 脑区形态继续使用 FreeSurfer 原生分区；VBM 继续默认体素结果。
- 新增 FreeSurfer 处理方式设置，默认保持逐随访处理。

## 验收标准

- DTI 四阶段人数由当前参数和检查集合动态计算，所有页面口径一致。
- 修改最大 b 值只使张量拟合和结果缓存失效；修改 QSIPrep 参数使预处理及下游失效。
- T1 两个分支分别显示已有结果、待补充处理和待生成结果数量。
- 只选择脑区形态或只选择 VBM 时，未选择分支显示本次不运行。
- 修改 FreeSurfer 纵向模式不影响 VBM 分支；运行设备不改变缓存命中。
- DTI 和 T1 均可进入对应的分析前检查弹窗。
- 桌面、390 px 和 320 px 无横向溢出，控制台无 warning / error。
- `npm test` 与 `git diff --check` 通过。

## 测试结果

- `npm test`：通过（构建与静态契约检查）。
- `git diff --check`：通过。
- 浏览器交互：DTI 默认分层为 44 次完整结果、7 次已有张量、11 次已有 QSIPrep、14 次需补充 QSIPrep；最大 b 值变化保留 QSIPrep，QSIPrep 参数变化使下游失效，图谱变化保留 44 次体素结果。
- 浏览器交互：T1 默认 FreeSurfer 119 次完整结果、7 次只需提取、37 次需处理；VBM 103 次完整结果、5 次只需发布、55 次需处理。取消某一结果后对应分支显示“本次不运行”。
- 浏览器交互：FreeSurfer 纵向模式只使脑区形态分支失效，VBM 仍保留 103 次结果；CPU/GPU 切换不改变缓存命中。
- 响应式检查：桌面、390 px、320 px 无页面级横向溢出；浏览器控制台无 warning / error。

## 风险和回滚

- 所有人数均为合成演示数据，不能迁移为真实科研状态。
- 正式系统必须由后端按不可变工件身份返回兼容结论。
- 可回滚到提交 `4aeb7a5`，恢复 DTI 和 T1 的静态阶段人数。
