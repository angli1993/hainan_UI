# 0009 模型中心与个体综合评估

状态：Verified

## 背景

平台已经按模态建立 BIDS、预处理、特征提取、缓存复用和结果空间边界。下一阶段需要把这些不可变特征工件作为模型输入：一方面由 Agent 辅助研究人员形成内部模型方案并完成训练、审核和发布；另一方面导入 UK Biobank 等外部队列训练的模型。新被试完成兼容特征后可运行已发布模型，并在患者随访中形成可审阅的个体综合评估。

## 目标

- 增加独立的“模型中心”，不改变 fMRI、DTI、T1、EEG 和图谱页面。
- 区分外部模型、内部模型和已发布模型；样板不虚构尚不存在的疾病进展预测模型。
- 增加“研究方案设计”，由方案助手把研究设想整理为研究对象、分组定义、研究变量、缺失规则和分析设计；后续训练与审核不作为并列顶层栏目。
- 展示模型所需特征、当前可用范围、验证设计、适用人群、模型版本和限制。
- 增加患者级“个体综合评估”，并列呈现外部参照模型、内部模型、原始测量、质控和随访变化。
- 明确模型输出为辅助科研信息，不自动形成诊断或处置建议。

## 非目标

- 不修改正式后端、数据库、任务调度或现有影像处理管线。
- 不在样板中执行真实训练、推理、SHAP、统计检验或报告签署。
- 不把外部模型与内部模型概率直接平均，不生成未经验证的综合风险分数。
- 不把实验中、仅交叉验证或未审核模型用于患者评估。
- 不声称 UKB 来源模型已经适用于海南人群或临床诊断。

## 设计

### 模型对象

正式系统至少应区分：

```text
ModelDefinition   研究问题、预测目标、分析单位和输入契约
DatasetSnapshot   冻结的患者、随访、标签与特征工件集合
TrainingRun       算法、超参数、随机种子、日志和验证结果
ModelVersion      模型文件、转换器、阈值、模型卡和审核状态
InferenceResult   模型版本对某患者某次随访的不可变输出
AssessmentReport  多来源结果的结构化汇总与医生审核记录
```

### 内部模型生命周期

```text
Agent 形成方案草案
-> 确定性输入契约检查
-> 冻结数据集快照
-> 按患者分组的训练/验证
-> 性能、校准和亚组评估
-> 技术与医学双审核
-> 发布不可变模型版本
-> 新被试满足条件后执行推理
```

预处理器、缺失值处理、标准化、特征选择和分类阈值必须在训练数据内拟合并随模型版本冻结。多次随访必须按患者分组，避免同一患者进入训练集和验证集造成数据泄漏。

### 外部模型接入

外部模型通过适配器登记模型文件、输入字段、空间和软件要求、参考人群、输出定义、论文、许可与本地验证状态。技术上可运行不代表临床可用；至少经过兼容性检查和本地回顾性验证后，才可进入医生端个体评估。

### 新被试推理

模型版本声明精确输入契约。系统按患者、随访和工件身份检查输入：全部兼容时可推理；存在可补算特征时回到该特征的最深兼容节点；缺少原始数据、标签或超出适用范围时停止并说明原因。模型不会触发无关模态重算，也不会因新增被试自动重新训练。

### 个体综合评估

患者页面并列展示：数据质量、原始测量、外部参照模型、内部已发布模型、随访变化和结构化解释。每项结果保留模型版本、输入检查、参考人群、阈值、校准状态和不确定性。方案助手只根据结构化结果生成解释草稿；医生可退回检查数据或确认评估记录，且不把不同任务或不同人群来源的分数无依据融合。

## 兼容影响

- 现有模态页面和工件复用逻辑保持不变。
- 左侧导航新增“智能分析”，包含“模型中心”和“个体综合评估”。
- 样板继续使用合成、去标识化数据，不调用真实模型或患者数据库。
- 正式实现需要新增模型注册、数据集快照、训练运行、推理结果和评估报告接口。

## 验收标准

- 模型中心清楚区分外部模型、内部模型及审核状态。
- 研究方案设计页清楚区分研究设想与可审核的结构化方案，并显式提示患者级数据划分和缺失值边界。
- 模型详情展示精确输入工件、输出、验证设计、适用范围和限制。
- 个体综合评估并列展示外部与内部结果，不产生单一自动诊断或无依据融合分数。
- 模型库使用“海南痴呆”命名，仅展示已有发布模型与外部验证模型，不展示虚构的 12 个月预测模型。
- 医生端使用“退回检查数据”和“确认评估记录”，不显示“提交医生审核”。
- 新被试流程说明输入检查、补算、推理、人工审核和随访比较。
- 桌面、390 px 和 320 px 无页面级横向溢出，控制台无 warning / error。
- `npm test` 与 `git diff --check` 通过。

## 风险和回滚

- 页面中的患者、模型、指标和性能均为合成演示数据，不得用于科研结论或临床判断。
- 外部模型存在人群、设备、采集和疾病谱迁移风险；本地验证状态必须显式展示。
- 可回滚到提交 `89cc363`，恢复仅包含数据和特征处理的样板。
