# 0010 视觉系统 v2：墨色主调与按需显示

状态：Implemented

## 背景

现有样板的视觉语言（浅绿品牌色 + 柔和色块 + 9–13 px 小字）识别度低，容易被认为是"模板化生成"的界面，也不利于医生在高分辨率屏幕上阅读。产品方希望界面具备更强的专业感与科技感（参考 Typeless、Azure 等产品的克制风格），同时保持医生端简洁：非必要信息默认收起。

## 目标

- 以单色（墨色 / 白 / 中性灰）为主、仅保留一个强调色，建立统一的设计令牌（颜色、字号、圆角、投影、动效）。
- 建立清晰的字号层级：页面标题 28 px / 正文 14 px / 辅助 12 px / 微标签 11 px，数字使用等宽数字。
- 应用壳升级：画布 + 侧栏 + 白色圆角主面板；侧栏按"工作台 / 数据管理 / 专业分析"分组；顶栏为毛玻璃并常驻。
- "本次方案"成为页面唯一的深色焦点卡片，突出医生需要确认的关键信息。
- 非必要信息默认隐藏：结果行的图谱明细只在展开"查看处理路径"时显示；样板提示缩为顶栏小标签。
- 增加外观切换（跟随系统 / 浅色 / 深色），深色模式通过 `color-scheme` 与 `light-dark()` 自动适配。
- 保持所有既有交互、数据语义、术语和事件处理不变。

## 非目标

- 不改变任何页面的信息架构、流程阶段、术语或演示数据。
- 不引入字体文件、CSS 框架或构建依赖；仍为零依赖单文件。
- 不新增伪造的患者、统计或任务数据来"填满"保留页面。
- 具体交互逻辑的调整（更 user friendly 的流程）另立变更文档。

## 设计

### 设计令牌

| 令牌 | 浅色 | 深色 | 用途 |
| --- | --- | --- | --- |
| `--icw-canvas` | #f4f4f5 | #0b0b0d | 画布与侧栏 |
| `--icw-surface` | #ffffff | #141417 | 主面板与卡片 |
| `--icw-text` / `-2` / `-3` | #0f1115 / #5b6170 / #8b909c | #f4f4f5 / #a1a1aa / #6f727c | 文字层级 |
| `--icw-line` / `-soft` | 9% / 6% 墨色 | 9% / 6% 白色 | 细线分隔 |
| `--icw-ink` | #0f1115 | #f4f4f5 | 主操作按钮、选中态、步骤序号 |
| `--icw-brand` | #2f6bff | #6b9aff | 唯一强调色：链接、聚焦环、"需图谱"标签 |
| `--icw-success` / `warning` / `danger` | 克制的绿 / 琥珀 / 红 | 同色提亮 | 状态点与状态标签 |
| `--icw-aurora` | 蓝 → 紫 → 青 渐变 | 同 | 仅用于品牌标识、Agent 头像、队列标记、主面板左上光晕 |

字号令牌 `--icw-fs-xs … 3xl`（11 / 12 / 13 / 14 / 15 / 17 / 20 / 28 px），圆角令牌 8 / 12 / 16 / 20 px，投影令牌 xs / sm / md / lg。

`light-dark()` 只能出现在颜色位置；渐变与投影在色标 / 颜色分量上使用 `light-dark()`，不得包裹整个值。

### 结构变化（仅壳层）

- 侧栏新增 `.icw-nav-label` 分组标签；品牌标识改为极光渐变方块。
- 顶栏 `.icw-demo-label` 文案缩为"样板模式"，完整说明放入 `title`；新增 `#icw-theme-toggle` 外观切换按钮。
- 主面板 `.icw-main` 为白色圆角面板，`::before` 绘制极淡光晕；顶栏 `position: sticky` + 背景模糊。
- 侧栏在桌面为 `position: sticky` 全高；≤880 px 时改为固定抽屉。
- `scripts/build.mjs` 的 `html, body` 背景与新画布一致，并按系统深色偏好切换。

### 按需显示

- `.icw-result-atlas`（结果行右侧的图谱说明）默认 `display: none`，`.icw-result.is-open` 时显示。
- ≤1180 px 时"本次方案"移到结果列表下方，避免两栏互相挤压。

### 外观切换

`#icw-theme-toggle` 在 跟随系统 → 浅色 → 深色 间循环，写入 `localStorage['hainan-ui-theme']`，通过根节点 `data-theme` 设置 `color-scheme`。该状态独立于宿主 widget state。

## 兼容影响

- 所有 `icw-*` 类名、`data-*` 钩子、元素 id 与事件处理保持不变。
- `check.mjs` 要求的全部标签仍在源码中。
- 新增类名：`.icw-nav-label`；新增 id：`#icw-theme-toggle`。

## 验收标准

- 桌面（1440 px）、390 px、320 px 下无横向溢出与文字遮挡。
- 四类弹窗（字段映射、阶段详情、图谱选择、分析前检查）、附件菜单、Toast 在浅色与深色下均可读。
- 键盘聚焦有可见焦点环；`prefers-reduced-motion` 下无动画。
- 控制台无错误或警告；`npm test` 通过。

## 测试结果

- `npm test`：通过。
- 本地 `npm run serve` 在 1440×900 下逐页截图核对：Agent 工作台、数据总览、静息态 fMRI、T1、平台图谱库、模型中心、个体综合评估。
- 窄屏与深色模式检查见 PR 截图。

## 风险与回滚

- 风险：深色主题下若某个局部仍写死浅色值会出现对比度问题；外观切换依赖 `light-dark()`（Chrome 123+ / Safari 17.5+ / Firefox 120+），旧浏览器退回浅色。
- 回滚：仅需还原 `src/integrated-clinical-workbench.fragment.html` 的 `<style>` 块、壳层 HTML 中的两处改动与 `scripts/build.mjs` 一行，然后重新构建。
