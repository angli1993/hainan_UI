# 0012 多套图谱方案、模型服务与隐私路由、Agent 确认与特征问答

状态：Implemented

## 背景

0011 落地后产品方提出一批调整：图谱方案应可同时执行多套并允许无限自定义；模板空间名称（MNI152NLin2009cAsym 等）不应在医生端显眼出现；图谱与模型都应带参考文献；本地部署策略未定，需要一个"去隐私后可调用国产外部模型并控制成本"的设计；特征库应能像 Paper2Agent 一样直接向特征提问；电生理也应有特征库；脑龄模型实为本院在 UK Biobank 数据上训练，应归入私有模型，同时登记真正开源的第三方模型；BIDS 与预处理阶段应能与 Agent 交互确认潜在问题；自动科研任务的"调用模型"混淆了 LLM 基座与临床数据模型。

## 目标与设计

- **图谱方案多选**：`state.schemesOn` 为集合，默认同时执行脑网络组方案与功能方案；`state.customSchemes` 为数组，可添加任意数量的自定义方案（可改名、三槽位选择、停用、删除）。脑区级特征对每套启用方案各生成一份结果；计算前检查与批量栏显示方案数量，需要图谱的特征预计时长按方案数相乘。
- **弱化模板空间**：新增 `atlasFriendly()`（如"脑网络组 210""Tian 皮下 54"）与 `spaceLabel()`（"MNI 2009c 模板"）；方案卡、特征抽屉、图谱目录列表与图谱选择弹窗均以友好名称为主，技术标识符退为次要文字或悬停提示；`softenSpaces()` 处理既有目录输出。
- **参考文献**：图谱目录补充 Tian、SUIT 文献；方案卡每个槽位显示首条文献与 DOI；模型卡新增"参考文献与代码"与"训练数据"。
- **模型服务与隐私路由**（新页面 `providers`）：路由模式（仅本地 / 本地优先 + 隐私路由）、四步规则（确定性拦截、本地分类、出院前过滤、审计）、预算与用量、国产外部模型（Kimi K3、GLM-5、DeepSeek-V3.2）的 API Key 与启用开关、路由审计表。对话页上下文与自动任务边界联动。设计参考 DSH Privacy Router 的"规则先行、不确定一律本地、云端不得触发工具"原则。
- **特征问答（问一问）**：特征抽屉内置由"特征技能"（论文、教程、验证代码）作答的小对话：预置问题芯片与自由提问；卡片与抽屉显示技能登记状态。
- **特征示意图**：卡片顶部改为每个特征的 SVG 示意图（波形、矩阵、梯度、网络、纤维、皮层带等），模态色只作顶部细条；后续可替换为真实截图。
- **电生理特征库**：新增页面 `features-eeg`，登记频段功率、功能连接、微状态、信号复杂度、非周期成分（均为规划项，带文献）。
- **模型调整**：脑龄预测模型（SFCN）改为内部模型，注明在 UK Biobank 数据上由本院训练；第三方模型新增 SFCN 开源权重（Peng 2021，MIT）、MedGemma 27B（Nature Medicine 2026）、pyment（Leonardsen 2022）。
- **Agent 确认**：BIDS 标准化、预处理、质控面板内嵌 Agent 提出的待确认问题（含建议与选项），回复后记录并可修改；每个阶段可一键"与 Agent 讨论此阶段"并把问题带入交互式挖掘。
- **自动任务弹窗**：数据集、六类模态与数据、LLM 基座（默认本地 Qwen，外部模型需开启隐私路由）、临床数据模型（默认勾选所有已发布模型，可选）、边界（含亚组稳定性检查与隐私路由开关）分开设置；任务详情分别显示 LLM 基座与临床数据模型。汇报抽屉新增折叠的亚组稳定性检查。

### 部署状态的准确表述

隐私路由开启后系统不再是"完全本地部署"，而是"本地优先的混合部署"。侧栏底部的部署状态随路由模式切换（本地部署 · 数据与模型均不出院 / 混合部署 · 隐私路由已开启），对话页上下文同步显示；模型服务页在开启时给出醒目说明，并要求院方信息安全部门确认分类策略、审计要求与供应商协议后再开启。样本级数据、影像与统计分析在两种模式下都只在院内。

### 本轮修复的缺陷

- 图谱目录的模板筛选按钮被友好名替换破坏了 `data-library-space` 属性，导致筛选后列表为空；`softenSpaces()` 改为只处理文本节点。
- "与 Agent 讨论此阶段"带入对话框的文字在离开后不会清除；现在渲染对话页后即清空。
- 侧栏"本地部署"文案在开启隐私路由后仍显示不出院；改为随模式切换。
- 预处理面板的"当前参数"仍显示模板空间标识；改用友好名。
- 自动任务弹窗把 LLM 基座与临床数据模型混在同一个下拉框；已分开，并补全模态列表。

## 非目标

- 不实现真实路由、计费、密钥存储；API Key 输入仅为演示。
- 特征问答为样板回答；正式系统由登记的特征技能生成并附出处。

## 验收与测试

- `npm test` 通过；20 个页面渲染无控制台错误；1440 px 与 390 px 无横向溢出。
- 方案启停、添加、删除、改名、槽位选择，特征问答，Agent 确认回复，路由模式与外部模型启停，自动任务创建均可操作。

## 风险与回滚

- 风险：第三方模型的指标摘自论文或仓库说明，正式登记时需模型管理员核对；隐私路由的分类策略需要安全部门审定。
