# 术语约定

| 页面术语 | 含义 | 不使用的替代词 |
| --- | --- | --- |
| BIDS 数据 | 在 Agent 工作台完成转换后，可供某一模态处理的标准化检查及其验证状态 | 数据接入、数据整理 |
| 预处理 | 校正、配准、标准化等上游处理 | 信号准备、形态学状态 |
| BOLD 信号去噪 | 按所选 fMRI 指标执行混杂信号回归、高头动帧处理和可选时域滤波；不是全部指标共用的一份结果 | 时间序列处理、fMRI 后处理、二次预处理、全局去噪 |
| 去噪 BOLD | 已按某一特征方案完成混杂回归、高头动帧处理及相应时域滤波的 BOLD 工件 | 可复用时间序列、后处理时间序列 |
| 特征提取 | 从合格上游产物生成指标、体素图、脑区表或矩阵 | 结果提取、算统计图 |
| 平台图谱库 | 神经影像公共图谱资源目录，保存图谱身份、空间、标签和审核状态 | 某一处理阶段 |
| 图谱查看 | 在模板背景上查看离散标签体图谱，支持三平面/3D、透明度、脑区提示与标签定位；样板只演示交互，正式系统使用 NiiVue 和真实 NIfTI | 统计分析、图谱审批 |
| 图谱选择 | 在具体特征中，从平台图谱库筛选并选择兼容图谱 | 图谱管理 |
| 脑网络组图谱（BN 210） | fMRI 指标的默认平台图谱；按当前 MNI 输出空间使用对应的 BN 210 文件 | 未经空间核对的通用图谱 |
| 无需补充处理 | 已有结果与当前指标的输入、参数、空间和图谱要求兼容，可直接进入该指标的特征计算 | 已经完成全部分析 |
| 功能梯度 | 基于图谱脑区功能连接结构提取的大尺度功能组织连续轴；作为独立特征配置与结果保存 | ReHo 参数、功能连接的附属结果 |
| 患者数 | 当前阶段涉及的唯一患者数量 | 样本量（未定义统计分析时） |
| 检查次数 | 患者与随访会话对应的处理单位数量 | 人数 |
| 脑区形态 | FreeSurfer 皮层厚度、表面积和皮层下体积结果 | RBM |
| 体素形态学（VBM） | deepmriprep 产生的调制组织图及组织体积结果 | 脑区形态 |
| 扩散张量拟合 | 从兼容的 QSIPrep 扩散像拟合单张量模型；最大 b 值属于该阶段配置 | 泛称扩散模型拟合 |
| DTI 指标生成 | 从兼容张量生成 FA、MD、AD、RD 体素图，并可按需追加脑区汇总 | DTI 特征提取（阶段名） |
| 脑区形态结果生成 | 从 FreeSurfer 原生分区产物读取厚度、表面积与结构体积 | 平台图谱提取、RBM |
| VBM 结果发布 | 登记 deepmriprep 组织图及 GMV、WMV、CSFV、TIV；可按需追加兼容图谱汇总 | 再次执行 VBM 预处理 |
| 最深兼容节点 | 当前检查与方案完全兼容的最下游既有工件；后续只补充缺失或不兼容步骤 | 从 DICOM 或 BIDS 无条件重跑 |
| 模型中心 | 登记内部与外部模型，管理输入契约、数据集快照、训练验证、审核、版本发布和推理权限 | 模型自动诊断页 |
| 输入契约 | 某一模型版本要求的特征身份、处理版本、空间、图谱、单位、字段编码和缺失规则 | 仅有字段名称的输入清单 |
| 数据集快照 | 冻结到具体患者、随访、标签与特征工件版本的训练数据清单 | 随数据库变化的实时查询 |
| 外部参照模型 | 在 UKB 等外部人群开发、通过适配器接入并单独记录本地验证状态的模型 | 已自动适用于本地临床的模型 |
| 内部已发布模型 | 在平台队列完成版本化训练、技术审核与医学审核，并明确允许用途的不可变模型版本 | 任意训练运行、交叉验证草案 |
| 个体综合评估 | 并列汇集质控、原始测量、纵向变化和各模型独立结果，由医生确认或退回的评估材料 | 自动诊断、未经验证的综合风险分 |
| 脑龄差 | 外部脑龄模型预测脑龄减实足年龄；需同时显示参考人群和本地校准状态 | 痴呆概率、生物学年龄诊断 |
