# 术语约定

| 页面术语 | 含义 | 不使用的替代词 |
| --- | --- | --- |
| 数据接入 | 身份核对、格式转换、采集信息与基础质控 | 数据整理 |
| 预处理 | 校正、配准、标准化等上游处理 | 信号准备、形态学状态 |
| fMRI 后处理 | 混杂回归、高头动帧处理、时间滤波 | 二次预处理 |
| 结果提取 | 从合格上游产物生成指标、体素图、脑区表或矩阵 | 算统计图 |
| 结果登记 | 保存数值、文件、质控、配置和来源 | 结果发布（仅本地登记时） |
| 患者数 | 当前阶段涉及的唯一患者数量 | 样本量（未定义统计分析时） |
| 检查次数 | 患者与随访会话对应的处理单位数量 | 人数 |
| 脑区形态 | FreeSurfer 皮层厚度、表面积和皮层下体积结果 | RBM |
| 体素形态学（VBM） | deepmriprep 产生的调制组织图及组织体积结果 | 脑区形态 |
