# 术语约定

| 页面术语 | 含义 | 不使用的替代词 |
| --- | --- | --- |
| BIDS 数据 | 在 Agent 工作台完成转换后，可供某一模态处理的标准化检查及其验证状态 | 数据接入、数据整理 |
| 预处理 | 校正、配准、标准化等上游处理 | 信号准备、形态学状态 |
| BOLD 信号去噪 | 按所选 fMRI 指标执行混杂信号回归、高头动帧处理和可选时域滤波；不是全部指标共用的一份结果 | 时间序列处理、fMRI 后处理、二次预处理、全局去噪 |
| 去噪 BOLD | 已按某一特征方案完成混杂回归、高头动帧处理及相应时域滤波的 BOLD 工件 | 可复用时间序列、后处理时间序列 |
| 特征提取 | 从合格上游产物生成指标、体素图、脑区表或矩阵 | 结果提取、算统计图 |
| 平台图谱库 | 神经影像公共图谱资源目录，保存图谱身份、空间、标签和审核状态 | 某一处理阶段 |
| 图谱查看 | 在模板背景上查看离散标签体图谱，支持三平面/3D、透明度、脑区提示与标签定位；样板只演示交互，正式系统使用 NiiVue 和真实 NIfTI | 统计分析、图谱审批 |
| 图谱选择 | 在具体特征中，从平台图谱库筛选并选择兼容图谱 | 图谱管理 |
| 功能梯度 | 基于图谱脑区功能连接结构提取的大尺度功能组织连续轴；作为独立特征配置与结果保存 | ReHo 参数、功能连接的附属结果 |
| 患者数 | 当前阶段涉及的唯一患者数量 | 样本量（未定义统计分析时） |
| 检查次数 | 患者与随访会话对应的处理单位数量 | 人数 |
| 脑区形态 | FreeSurfer 皮层厚度、表面积和皮层下体积结果 | RBM |
| 体素形态学（VBM） | deepmriprep 产生的调制组织图及组织体积结果 | 脑区形态 |
